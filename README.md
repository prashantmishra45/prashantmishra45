## 📂 Featured Projects

### 🚩 [LaunchLite](https://github.com/prashantmishra45/LaunchLite) — Multi-Tenant Feature Flag & Remote Configuration SaaS

A self-hostable, LaunchDarkly-inspired SaaS engine for multi-tenant feature flag management and remote configuration.

- Engineered a scalable Spring Boot 3 backend with tenant isolation, JWT/API-key authentication, and PostgreSQL persistence
- Achieved **sub-5ms flag evaluations** at the SDK layer via Redis caching and an AOP-based rate-limiting layer
- Built an event-driven architecture with Kafka and WebSocket/SSE broadcasting to push real-time flag updates to connected clients without polling
- Instrumented full production observability using Prometheus + Grafana, and containerized the entire stack (API, frontend, Kafka, Redis, Postgres, monitoring) with Docker Compose for one-command deployment

### 🎙️ [AMIII](https://github.com/prashantmishra45/My-Voice-Assistant) — Modular Voice-Controlled AI Assistant

An open-source, documentation-driven AI operating assistant that converses, automates tasks, and controls applications through voice.

- Built a pluggable LLM provider layer supporting local (Ollama) and cloud (Groq) inference, with automatic fallback between them for reliability
- Implemented a full voice pipeline — Faster-Whisper for STT, Piper for TTS — for low-latency, real-time voice interaction
- Designed LLM-based intent routing to automate app launching, browser automation (via Playwright), web search, media playback, and desktop tasks via natural voice commands
- Backed every feature with architecture decision records, unit tests, and an engineering journal — treating it as both a working product and a structured learning project
